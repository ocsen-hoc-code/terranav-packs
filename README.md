# TerraNav offline packs

Map and routing packs for the TerraNav Android app, published as GitHub release `packs-v1`.

- `catalog.json`: list of packs with size, SHA-256 and download URL.
- `vn.pmtiles`: Vietnam basemap (Protomaps extract).
- `vn-routing.tar`: Valhalla routing tiles for Vietnam.

Data sources: map data © OpenStreetMap contributors, licensed under ODbL 1.0 (https://www.openstreetmap.org/copyright). Basemap schema © Protomaps, CC BY 4.0.
